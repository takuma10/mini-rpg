# Mini Dungeon RPG

ターミナルとElectronで動くミニRPGゲームです。

## 遊び方

### ターミナル版

```bash
python game.py
```

### デスクトップ版 (Electron)

```bash
npm install
npm start
```

## 操作方法

| キー | 動作 |
|------|------|
| `w` | 上に移動 |
| `s` | 下に移動 |
| `a` | 左に移動 |
| `d` | 右に移動 |
| `q` | 終了 |

## マップ記号

| 記号 | 意味 |
|------|------|
| `@` | プレイヤー |
| `E` | 敵 |
| `B` | ボス |
| `*` | アイテム |
| `X` | 出口 |
| `#` | 壁 |

## ゲーム目標

ボス (`B`) を倒して出口 (`X`) に辿り着けばクリアです。

## 動作環境

- Python 3.8+
- Node.js 18+ / Electron 42+
